# S4 Prompt-to-image + provenance: progress report (2026-10-16)

Status: **done**. Everything in DESIGN.md §11 row S4 is built. §4.4, §6.2, §6.7, §1.2 S-f and §9.2 are implemented.

## Built
- `pipelines/prompt_templates.py`: `build_prompt` with the exact §4.4.3 texts, the light-subject → `medium-gray`
  background rule, `expected_terms` (user prompt only), and `prompt_sha256` / `prompt_log_tag` (length plus 12 hex).
- `processing/imagegen_readiness.py` (§4.4.5): Lab border median, ΔE > 12, 3 px open, the five `t2i_*` issues.
- `pipelines/image_generation.py`: `ImageGenerationExecutor` with phases `cpu[load_model]` → `gpu[generate]` →
  `cpu[check, save]`. A model already in RAM is `skipped` ("Model already in memory"). Seeds are
  `(seed + i) mod 2^31`. Errors map to `generation_failed`; OOM is passed through.
- `services/image_generation_service.py`: create (flag → 503; registry/model → 503 `capability_unavailable` /
  `model_unavailable`; static VRAM check; 422 `unsupported_by_model` / `conflicting_fields` / `string_too_long`; 429),
  plus get/list (live snapshot), cancel (queued or running; 409 terminal), delete (409 active or guarded), candidate
  files, and `use_candidate` (real `ReferenceService.upload_image(..., source=ImageSource)`, `used_as` persisted, a
  new set is removed if the import fails).
- `api/v1/image_generations.py`: every §6.2 route. An `{index}` that does not match `^[0-3]$` returns 404.
- `inference/imagegen/zimage.py`: `ZImageTurboProvider(spec, settings, *, model_dir=None)`, which matches the S2
  registry's construction. `load()` runs on the CPU and does a **sequential prefetch** of all weight files, then
  `from_pretrained` (bf16, `local_files_only`), then materialises every tensor in RAM. `generate()` moves the
  components to the GPU one by one, uses batch size 1 with a private Generator, and empties the cache after each
  decode. Cancellation works through `callback_on_step_end` / `_interrupt`. Weights go back to the CPU in `finally`.
- S-f: `ImageSource` and `ReferenceImage.source`. A wrap serializer drops the key when it is None, so `set.json` stays
  key-identical. `ImageSourceOut` has no prompt hash. `upload_image(..., source=)` is keyword-only.
- `requirements.txt`: `diffusers==0.39.0` and `accelerate==1.15.0` under a "Part-aware (text-to-image)" heading.

## Deviations
- `load()` keeps the default `low_cpu_mem_usage`. It uses the §5.6 fallback (explicit materialisation) plus a
  sequential prefetch, which is not in DESIGN but is what fixes the cold load on the HDD.
- `{subject}` is collapsed to one line and loses a trailing full stop (avoids "..").
- An unknown `model_id` returns 422 `unsupported_by_model` (lists the allowed ids). A known but unusable model returns
  503 `model_unavailable`.
- The smoke test needs the opt-in `IMG3D_GPU_SMOKE=1`, because the full suite collects `test/aux_models` and would
  otherwise load 33 GB without the lock.
- Additive service API: `add_delete_guard(fn)` and `list_for_workflow(wf_id)`. The constructor is unchanged.
