## Built
- Submodules (`git submodule add`, nothing else in git; staged by that command only):
  `backend/third_party/see-through` @ `df019de5129d6c4b406587a14c3501669441a783` (Apache-2.0),
  `backend/third_party/sapiens2` @ `7e5bae88456ac418ff0e58e74106c9fe192055d4` (Sapiens2 License). No requirements installed.
- `inference/providers/vendor_import.py` (stdlib): `VendoredPackage(name, root, *, source_dir=None)` + one `sys.meta_path`
  finder for `img3d_vendor.*` only. An AST rewrite maps own absolute imports and keeps the same bindings. No bytecode
  is written (verified: both submodules stay clean). Source roots: see_through → `common/`; sapiens2 → `sapiens/backbones/standalone/`.
- `inference/segmentation/see_through.py`: `SeeThroughProvider` builds `SemanticSam(19)` on empty weights, then
  `torch.load(weights_only=True)` + `load_state_dict(strict=True, assign=True)` (bf16 checkpoint, all keys match).
  Also `VendoredParserProvider` + `masks_from_planes`/`split_sides` (shared, numpy): 8-bit soft PNGs, score 0..1,
  eyes/ears split by connected components relative to the face centre (image-right = character left), ears above the face → `appendage.animal_ears`.
- `inference/segmentation/sapiens2.py`: `Sapiens2Provider` = vendored standalone `Sapiens2` backbone + head, safetensors
  `strict=True` (424 keys). 1024x768 input, softmax over 29 classes; L/R are person-relative and map directly.
  Upper/lower limbs, shoes, socks and lips/teeth/tongue are merged. `Background`/`Apparel` are not emitted.
- `THIRD_PARTY_NOTICES.md` (S6 rows: §1 restriction, §2 models, §3 submodules + note), `backend/third_party/README.md`.
## Deviation (no install needed)
- Sapiens2's `SegHead` sits behind `sapiens/__init__`, which imports the training engine. That engine needs termcolor,
  rich, matplotlib and iopath (not installed). So the head's layers (ConvT/InstanceNorm/SiLU ×4, Conv ×2, 1x1) are
  re-declared in `sapiens2.py` with the upstream parameter names. Only the standalone backbone file is vendored-imported.
