## Deviations
1. A missing implementation module -> `unavailable/not_implemented` (design: `error` for any exception); a broken
   import/constructor still gives `error` with `"<Type>: <msg>"`.
2. `PartProviderOverrides.providers` stand in for the installed model: rules 5-8 skipped, policy rules 1-4/9 kept.
3. `ensure_vram(ids)` requires the SUM of the phase models' peaks + margin.
4. "In use by the running run" (409) is by run kind (ig -> text_to_image; sg -> segmentation; pa -> segmentation +
   part_extraction); RunWorker exposes no model ids.
5. Unload is async: the 202 body can still say `loaded`; state flips to `installed` when the GPU task ends.
6. `api.{image_generations,segmentations,part_analyses}` = executor module present; `api.workflows` =
   `services.workflow_compiler` present. `cold_start_s` is `null` when the T2I model is `loaded`.
7. Catalog assumptions [A]: `ram_gb` of the seg models/lifter; Tencent licences `commercial="unknown"`.
8. No idle-unload sweeper (default off, no owner in §11); only `idle_providers()` exists.
