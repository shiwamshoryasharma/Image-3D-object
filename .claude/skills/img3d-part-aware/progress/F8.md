**Deviations.**
1. The parts model is *drawn* only while `view.show` is on; hover/select/hide/isolate with Parts view off only mount (preload) it. Hide/isolate/select therefore show nothing until Parts view is on (see the F7 request).
2. `buildPartsIndex(root, set, regionAttribute)` takes the set (binding derived inside, cached per set). Region subsets per value are built in one pass and kept per host (bounded by one index copy); the hide/isolate subsets use an LRU of 8.
3. Colorize: the host colour sits under the region overlays (polygon offset −1 vs −2) instead of a "host minus regions" subset. Hover/select use −4.
4. No tween at all for explode (instant for everyone, so reduced motion holds).
5. "Loading" is set by the parts Suspense fallback (`PartsLoading`) instead of a ModelViewer effect, so a cached GLB never gets stuck in "loading".
6. Viewer chip text "Highlight unavailable for body regions" (per-row wording is F7's).
