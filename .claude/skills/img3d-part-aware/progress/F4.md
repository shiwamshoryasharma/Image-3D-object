## Deviations from UI_DESIGN.md
1. **Dialog close button grows instead of a `::before` hit area.** §3.6 names "dialog close" as an example of an
   icon button whose visual size stays. Its `IconButton size="sm"` already follows `--control-h-sm`, so it becomes
   44/48 px under touch, which any bounding-box probe accepts. The Sheet close button behaves the same way. The
   reference star and menu do use `::before`, as specified.
2. **`data-default-bar="off"` added to the P11 contract.** It is optional. It lets the Default phone layout report
   that it is visible with the bar hidden (the Viewer and History tabs). With it, toasts clear the tab bar even where
   the `max-width: 767px` media rule does not apply (P7 phone landscape, 812×375). Without it, behaviour equals the
   spec.
3. **Tokens added beyond the §4.2 list:**
   - `--color-primary`, `--color-primary-hover`, `--color-primary-pressed` and `--color-on-primary` name the P13
     button colours.
   - `--progress-ring-track`, so the new modules carry no literal colours.
   - `--z-sheet`.
   - `--keyboard-inset` and `--default-bar-height` in `modes.css`.
4. **P14 (transitions):** F4 did the `Panel` card entry. The Dialog exit animation was **not** added. `Dialog.tsx`
   unmounts its surface as soon as `open` turns false, so an exit fade would only show an empty box. Keeping the
   content mounted would change Dialog behaviour. P14's "Where" column lists AppShell, Panel and HistoryDrawer CSS
   only. `Sheet` has a full entry/exit animation.
5. **Extra unit tests.** §10.2 lists no F4 test file. The three test files above test F4-owned modules (rule: tests
   belong to the module's owner).

    `_img3d-spin_<hash>_1`, which has no `@keyframes`. Verified in both the `8654b90` build and this build.

    `img3d-fade-in` fades (Dialog, Menu, EngineStatus popover, BackendBanner) and the `ConnectionIndicator` pulse never
    run.
  - Proven fix: local `@keyframes` in each module, as `ProgressRing`, `Skeleton` and Toaster's `enter` do.
  - Left untouched: it changes motion in the Default UI, and most affected files belong to other slices. User
    decision needed.
