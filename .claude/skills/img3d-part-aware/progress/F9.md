**Requests.**
- **bundle_budget.mjs owner (F0/F11):** the Mobile row is over-counted. The shell chunk statically imports `index.html` (shared entry modules), and `reach()` then follows the entry's dynamic imports: featureBundle, tunerBundle, ModelViewer, AppSettingsBody and the other shells. Result: "Mobile shell + shells/shared" shows 83.7 kB (real 12.5 kB), and "Tablet (excluding shared)" always shows 0. Fix: stop the walk at `entryStatic` keys, e.g. `reach(key, {stop: entryStatic})`. With that walk the final numbers (F10 build) are Mobile + shared 13.07 kB ≤ 22 and Tablet own 2.47 kB ≤ 12. Lazy-loading more in the shell would not change the script's number: any shell chunk imports `index.html`.
