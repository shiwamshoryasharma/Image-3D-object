# S7 Raster lifter (verified 2026-10-22)
## Built (the stopped run's files were complete; no code change this session)
`inference/parts/raster_lifter.py` contains `RasterLifterProvider(LabelLifter)`. Its registry key is
`nvdiffrast_raster` and its catalog id is `raster_lifter`. It covers the whole frozen S1 ABC:
- `upload` / `release`
- `fit_camera`: silhouette-IoU grid search, refine, mirror tie-break, front-view fallback when rejected
- `raster`: triangle ids + depth; ids > 2^24 are decoded on the GPU
- `render_textured`, `render_labels`
- honest lifecycle states, plus `offload` / `unload`
`inference/parts/cameras.py` is torch-free: the grid (756 coarse + 605 refine), distance rule, look-at and crop
intrinsics, the upstream framing crop, extra-view schedule, IoU, and id encode/decode.
`test/backend/fakes_lifting.py` provides `FakeLabelLifter`, a CPU fake for S10. A test checks it against the real raster.
