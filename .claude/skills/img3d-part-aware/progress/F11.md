**Deviations.**
1. No step thumbnails in node bodies: §1.4 forbids shells → URL helpers, and the store layer may not import them either. `projectRunState` gets an identity resolver.
2. `toFlowEdges(doc, registry, statuses, reducedMotion, selection, linkStyle)` takes the registry (for the source-port colour) and the link style.
3. "Load these settings" restores prompt, part, segmentation-terms and export params. `image_to_3d` params are not written back (they would need a GenerationSettings → SettingsForm mapping). Unknown keys are counted and a warning toast is shown.
4. Problems open as a Dialog. With nothing selected, the Inspector shows progress, problems and the summary. The toolbar groups Templates/Tidy/Import/Export in one "Workflow" menu to fit 48 px.
5. Sync from stores records no history entry. Undo/redo renumber revisions.
6. `vendor` still holds `zustand/traditional` + use-sync-external-store, because @react-three/fiber imports them from the top-level zustand 5. The size equals the baseline (1.93 kB).
